# E-KKO – Elektroniczna Karta Kontroli Obiektu A33

Karta kontroli czystości na telefon dla budynku A33 (Nowy Rektorat). Otwórz stronę w przeglądarce telefonu i wybierz „Dodaj do ekranu głównego”.

Strona nie zawiera danych osobowych. Imiona zespołu, podpis i kontrole są zapisywane tylko w pamięci telefonu, na którym ich używasz. Strona niczego nie wysyła; raport przekazujesz sam przez WhatsApp.
